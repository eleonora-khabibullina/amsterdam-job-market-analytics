# Amsterdam Job Market Analytics

An end-to-end data analytics project exploring the
job market for Data Analysts and Product Analysts
in Amsterdam.

## Project Goals

- Collect job postings from public sources.
- Identify the most in-demand analytical skills.
- Compare job requirements across companies and roles.
- Track changes in the job market over time.
- Build an interactive analytics dashboard.

## Tech Stack

- Python
- PostgreSQL
- SQL
- Git and GitHub
